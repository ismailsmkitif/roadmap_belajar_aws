Bagaimana Website Ini Dihosting?

Website portofolio ini berjalan di arsitektur serverless yang aman dan hemat biaya menggunakan layanan AWS:

🌐 Pengunjung HTTPS Client
→
⚡ Amazon CloudFront CDN & OAC Edge
→
🔒 Amazon S3 (Private) Origin Bucket
Keamanan: S3 Bucket sepenuhnya privat. Akses hanya diizinkan melalui CloudFront Origin Access Control (OAC).
Performa: Aset di-cache di ratusan Edge Location CloudFront di seluruh dunia untuk latensi ultra rendah.
Roadmap Pembelajaran

4 Fase Proyek AWS

Rangkaian proyek hands-on yang dibangun di AWS Academy Learner Lab.

Sedang Berjalan (Fase 1)

Static Website Portfolio & CDN

Hosting portfolio modern dengan S3, CloudFront HTTPS, Origin Access Control (OAC), cache invalidation, dan Block Public Access.

Amazon S3 CloudFront OAC HTTPS
Fase 2

Three-Tier Web Application

Pemisahan Presentation, Application, dan Database Layer di dalam custom VPC dengan Public & Private Subnet serta RDS MySQL.

VPC EC2 RDS db.t3.micro NAT Gateway
Fase 3

High Availability & Auto Scaling

Infrastruktur tahan bencana dengan Application Load Balancer (ALB), Auto Scaling Group lintas Multi-AZ, dan CloudWatch Alarms.

ALB Auto Scaling Multi-AZ CloudWatch
Fase 4

Serverless Architecture & CI/CD

Backend serverless berbasis event-driven menggunakan API Gateway, Lambda, DynamoDB, otomatisasi IaC (SAM), dan GitHub Actions.

AWS Lambda API Gateway DynamoDB GitHub Actions
